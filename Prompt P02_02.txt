tolong bantu buat aku membuat code program bahasa c yang dapat membantu menentukan total stok hanya untuk kategori barang yang diminta dalam suatu rak gudang yang tersusun rapi. Jadi alur penyelesaiannya ini seperti input yang diterima program ini adalah Jumlah total data (N), kemudian deret stok (s1,s2,...,sN), serta kode kategori barang, untuk kode kategori barangnya ini kita bebas membuatnya. Kemudian ada diberikan suatu pola penyimpanan di suatu gambar untuk memahami bagaimana kelompok barang dipisahkan, jadi gambar nya itu disini aku deskripsikan, yaitu ada 4 buah kertas seperti ditumpuk tapi masih kelihatan bagian atasnya, di kertas pertama ada tulisan 120pcs minyak, kertas kedua ada tulisan 5 pcs rok pramuka, kemudian gula itu 85 pcs. dan dikertas terakhir ada tulisan 22 pcs dasi SD. Situasi yang digunakan dalam menggunakan program ini yaitu ketika user akan menghitung stock barangn, lingkungan yang digunakan yaitu lingkungan kerja seperti gudang stock barang dan kondisi data ynag sedang diproses itu kira kira seperti yang aku berikan di atas. output nya kita buat aja dia seperti sebuah struk atau lish, nama barang dengan jumlah stock yang masih ada di gudang itu. aturan atau larangan tertentu tidak ada, kita hanya perlu menggunakan code yang sederhana, kemudian untuk batasan juga tidak ada, cari code program bahasa c yang paling sesuai dengan maksud aku dan konndisi khusunya untuk permasalahan ini mungkin tidak ada, kalau pun ada tolong buat keterangannya.
